# Masterarbeit_2026
Hier werden die Graphiken der Masterarbeit zum Thema Rekonstruktion des Depositionsgeschehens von vulkanischen Aschen als Grundlage für ein besseres Verständnis der Bodenbildung zur Verfügung gestellt. 
Die interaktive Karte in Kapitel 5.2 ist in einem zip-Ordner abgelegt, indem sich die .html Datei und die files befinden. Die Graphik kann ohne die files nicht geöffnet werden und diese müssen im gleichen Ordner gespeichert sein.
